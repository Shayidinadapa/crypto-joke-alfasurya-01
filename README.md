# Laugh Track: The Crypto Trading Joke Contest

Entry for the [make.fun bounty "Laugh Track: The Crypto Trading Joke Contest"](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a).

`main.ts` writes a single one-line joke about crypto and trading life (under 200 characters) to `/output/entry.txt`, validates it against the competition gate (1–200 characters, one line, not only white space), then reads it back and throws on any mismatch.

Run it with:

```sh
node main.ts
```
